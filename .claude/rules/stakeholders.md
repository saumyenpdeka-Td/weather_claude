# Stakeholders — Weather App

Maps project roles to the canonical names used in user story titles. Story
titles must use a role from this file.

## Business roles (story actors)

| Canonical role | Description | Notes |
| --- | --- | --- |
| Weather App User | Any person using the app to check current weather conditions for a location. | The sole end-user persona for this MVP — no accounts, teams, or admin roles in scope. |

## Roles that are NOT valid story actors

| Invalid | Correct replacement |
| --- | --- |
| User | Weather App User |
| System / Platform | Not a story actor — describe the outcome for Weather App User |
| Admin | No admin persona defined yet for this app — flag to stakeholder if one emerges |

## Stakeholder contact map

| Role | Requirement owner | Contact method |
| --- | --- | --- |
| Weather App User | Product owner (requester) | Direct request via this Analyst session |

## Adding a new role

1. Add the canonical name and description to the table above.
2. Confirm with the requirement owner before using it in a story.
3. Check no existing role is a synonym.
